# Компактная спектрограмма

Пример **Compact spectrogram: frequencies and notes** собирает обычные
редактируемые узлы. Loopback выбран по умолчанию; InputSelector переключает
его на микрофон или генератор. Отдельный clock/rate-выход сопровождает каждый
вход. Физические источники публикуют один mono-выход; выбор дополнительных
каналов и их смешивание выполняются явно.

## Обработка

`InputSelector → Converter → PcmResampler → FrameBuffer → Converter → ArrayMultiply
→ RealFourier → AmplitudePhase → ArrayMultiply`.

- Первый Converter переводит нормированные PCM-амплитуды в Int16 с насыщением
  и округлением к ближайшему чётному. `speex_q15`, качество 5, работает с
  Int16 и выдаёт Int16 при 36 кГц. Loopback/микрофон могут объявлять другую
  входную Fs; файловая проверка явно готовит 48 кГц общим FIR frontend.
- FrameBuffer накапливает Int16 с явно заданными size=4096 и hop_samples=600
  при 36 кГц. Первый кадр появляется после полного заполнения окна;
  последующие кадры перекрываются и поступают с частотой 60 Гц.
- Второй Converter нормирует Int16 в Float32 непосредственно перед оконным
  умножением. WindowFunction задаёт `hann` с `periodic=true`: знаменатель косинуса N,
  сумма коэффициентов N/2. Существующий `hann` остаётся симметричным (N−1).
- RealFourier использует существующий раздельный контракт: Re из 2048 значений k=1…2048, Im из 2047 значений k=1…2047;
  мнимая часть Nyquist равна нулю, DC вынесен в отдельный scalar-порт.
  AmplitudePhase выдаёт отдельные массивы амплитуд и фаз; `peak_amplitude`
  получает сам вектор коэффициентов отдельным входом `window_coefficients_input`.
  WindowFunction не имеет выходов сумм/энергии. При включённой компенсации
  AmplitudePhase вычисляет необходимые поправки из этих коэффициентов при подготовке;
  при выключенной — выдаёт сырые значения без FFT/оконной компенсации. Nyquist
  не удваивается. Размер FFT подключён явно от ArrayLength окна.
- ArrayFill хранит 2048 заданных коэффициентов Billboard для k=1…2048; ArrayMultiply
  применяет их к амплитудам. Это перенесённая на сетку 36 кГц статическая
  кривая, **не новое измерение Billboard с frontend 36 кГц/Q15**.
  Происхождение и SHA-256 исходной таблицы сохранены в
  `apps/default_graphs/src/compact_spectrogram_frequency_profile.h`.

BroadbandFeatures с `statistic=maximum`, `first_bin=1` получает 49 явных
границ для 48 непустых полос. Шаг частот подключён от FrequencyStep.
Семь последовательных разделов: Бас 40–250 Гц (12), Плотность 250–800 (4),
Удар 800–1500 (6), Щелчок 1500–3500 (8), Шум 3500–6000 (6),
Шелест 6000–10000 (4), Воздух 10000–16000 (8).
Внутри каждого из семи разделов границы равномерны по Гц. Это явные параметры примера,
а не распознавание конкретных инструментов. Все разделы используют максимум
исправленных линейных амплитуд, без RMS, усреднения или dB.
Бас объединяет 24 исходных значения FFT в 12 пар; остальные полосы также непусты.

NoteSpectrum независимо интерполирует исправленные амплитуды на 48 частотах
MIDI 48…95 (C3–B6, 130,81–1975,53 Гц), строй A4=440 Гц. Это амплитуды в
нотных точках, а не распознавание нот или harmonic salience.

ArrayConcat соединяет `[48 широкополосных][48 нотных]`. SpectralQuantize
кодирует оба набора одинаково: `floor(255*clip(a,0,1)+0.5)`.
Один Spectrogram хранит **512×96 UInt8 = 49 152 байта полезных значений**.
Метаданные, рабочие буферы FFT и проекция GUI в эту цифру не входят.
К одной истории подключены два представления: CompactSpectrogramView (2D) и
AudioSurfaceView (3D), с одинаковой шкалой и разделением 48+48 каналов.
Компактный 2D-блок показывает одну историю с двумя нижними осями:
индексы каналов и отдельные частотные/нотные разделы. Новейший кадр имеет
возраст 0; прокрутка по умолчанию идёт снизу вверх. Шкала линейная, UInt8
0…255. Направление переключается в параметрах представления.

## Проверка и сохранение конфигурации

Из корня checkout, с настроенным Qt/toolchain окружением:

```powershell
cmake --build --preset release --target compact_spectrogram_pipeline_tests compact_spectrogram_tests
./cmake-build-release/bin/compact_spectrogram_pipeline_tests.exe --export-project .agent-workspace/spectrogram-integration/config.json
./cmake-build-release/bin/compact_spectrogram_pipeline_tests.exe --synthetic .agent-workspace/spectrogram-integration/config.json .agent-workspace/spectrogram-integration
$env:QT_QPA_PLATFORM='offscreen'
$env:QT_QPA_PLATFORM_PLUGIN_PATH="$env:QT_ROOT/plugins/platforms"
./cmake-build-release/bin/compact_spectrogram_tests.exe .agent-workspace/spectrogram-integration
```

Синтетическая проверка подаёт меняющиеся тоны непосредственно в PreparedGraph,
без воспроизведения и устройств захвата. Она проверяет группирование,
интерполяцию, квантование, шаг и кольцевой порядок обеих историй.
Для проверки внешнего музыкального файла вместо `--synthetic config.json`
передайте путь к файлу; второй аргумент — каталог результатов.
`history-512x96.u8` содержит хронологические строки, `processing.json` —
параметры и счётчики, `spectrogram-loopback.json` — отдельную конфигурацию.
Проверка представления создаёт изображения через production QWidget renderer
в Light и Dark. Это offscreen-проверка, не приёмка нативного GPU или захвата.

Не задавайте тестовые Qt-переменные для обычного запуска GUI.
Пользовательская конфигурация автоматически не заменяется.

Размеры преобразователя, измерителя длины и зависимых узлов обновляются в
черновике даже при несовместимом узле в другой ветви. Применение несовместимого
черновика по-прежнему запрещено. Таблица Billboard относится к сетке 36 кГц /
FFT4096: смена N требует явной подготовки коэффициентов на новой сетке;
таблица не обрезается и не растягивается молча.


### Представление ритмических областей

CompactSpectrogramView показывает одну историю 512×96 UInt8 с двумя нижними
осями: ближайшая к изображению — индексы и границы разделов, следующая —
частотные и нотные отметки. Под ними расположены семь отдельных подписей
и Ноты; общей группы «Атаки» нет. `compact_layout.broadband_sections` содержит
явные label/begin/count, `broadband_centers_hz` — центры полос, подготовленные
общим DSP-процессором, `first_midi` — начало нотного диапазона. Названия
переводятся в RU/EN. При недостаточной ширине подписи наклоняются целиком.

ClassicSpectrogramView показывает отдельную историю полного спектра
64×2048 UInt8 по умолчанию. Ёмкость обеих историй редактируется пользователем
без отдельного искусственного максимума: предел определяется представимостью
размера и фактическим выделением памяти. Обе по умолчанию прокручиваются снизу
вверх, направление меняется в параметрах. Палитра и линейная шкала 0–255 общие.
Оконная обработка, Billboard и 48 нотных каналов при смене разделов не меняются.
Статья AI-Science не изменяется. Детектор перкуссионных атак здесь не добавлен:
эта схема сохраняет амплитуды для отображения и последующего анализа.

Интерактивный каталог содержит «Анализ ритма: librosa» (`reference-beat`)
и «Компактная спектрограмма: частоты и ноты» (`compact-spectrogram`).
Остальные вычислительные примеры остаются тестовыми fixtures вне меню пресетов.
