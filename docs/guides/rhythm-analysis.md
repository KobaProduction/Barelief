# Комплексный спектрально-ритмический пример

Стандартный стартовый пример использует **Loopback** и один общий аудиотракт:
SpeexDSP (32768 Гц) → окно Hann (4096) → RealFourier → AmplitudePhase →
ArrayMultiply (линейная амплитудная коррекция).

В **ArrayFill #1005** уже включены 2048 измеренных линейных коэффициентов
из сохранённого проекта пользователя (профиль: 32768 Гц, FFT 4096,
Hann, SpeexDSP). При формировании примера исходный пользовательский
config.json не изменялся. Множители применяются до анализа признаков.
Штатный AudioLineView #1110 отображает кривую коэффициентов по частоте,
а график спектра #10 — скорректированные амплитуды.

Спектральные признаки формируются из обычных, уже существовавших узлов:
**BroadbandRow #6**: 24 низкочастотных, 8 среднечастотных и
16 высокочастотных полос (48);
**NoteSpectrum #1006**: 48 нот, MIDI 36–83.
**ArrayConcat #1007** формирует строго 96 частотных/нотных признаков.
Стандартный SpectralQuantize #1111 (8 бит, диапазон 0–1) преобразует
Float32 к Uint8 без отдельного модуля извлечения ритмических признаков.
Один **Spectrogram #7** накапливает 512 кадров × 96 полос и одновременно
подключается к существующему ритмическому анализатору #1102 и
просмотру спектрограммы #8. Нет повторной FFT, RhythmFeatures или
второго накопителя ритмической спектрограммы.

Ритм вычисляется 60 раз/с. Стандартный ScalarMetricsView #1103 показывает
текущие ритмические величины; **NumberAccumulator #1105** сохраняет
историю кандидата BPM, **VectorLineView #1106** отображает эту историю
на шкале времени. Алгоритм DSP-ядра RhythmAnalyzer и его контракт
96-полосного Uint8-входа не изменены.

Дополнительные истории широкополосного и нотного рядов (#1008 и #1010)
остаются доступны для отдельных спектрограмм. Пользовательский файл
проекта не изменяется; обновлённый пример нужно открыть явно.

Диапазон квантования 0–1 описывает нормализованные амплитудные
значения, а не коэффициенты усиления: сами множители могут быть
больше единицы и не конвертируются в децибелы. При превышении
амплитудой единицы штатный квантователь ограничивает значение 255.
