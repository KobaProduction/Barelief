# Работа с интерфейсом

[Документация](../README.md) · [Термины](../architecture/README.md#термины) · [Устройство интерфейса](../architecture/interface.md) · [Графики](graphs.md)

`core_app` — графическое Qt-приложение. Оно позволяет собирать схему обработки
на полотне «Поток данных»,
выбирать процессор и наблюдать результаты в отдельных графических панелях.
Порядок запуска описан в [сборке и запуске](../reference/build-and-run.md).

## Схема и параметры

Добавьте узел из каталога или контекстного меню полотна. Его карточка на полотне
называется блоком. Источники создают
данные, обработчики преобразуют их, выходы потребляют или отправляют результат.
Один входной порт принимает одно соединение; выход можно соединить с несколькими
потребителями. Для смешивания используется Mixer, для преобразования Fs —
Resampler. Переключатель выбирает группу отдельных каналов одним действием.

Карточка показывает название операции, порты, основные параметры и краткое
состояние. Выберите узел, чтобы открыть полный инспектор. «Показывать на блоке»
выносит дополнительное поле на карточку, сохраняя то же значение.
Переименование меняет подпись объекта, а не его тип и идентификатор.

Порты показывают числовой тип (например, Float32 или UInt64), форму и назначение.
Одинаковая длина двух массивов ещё не делает их совместимыми для вычисления. Отдельные
конфигурационные связи передают происхождение Fs и частотной сетки;
они не являются аудиосигналом. У History выход «Заполнено кадров» — счётчик,
а «История» — матрица накопленных данных. Ёмкость накопителя и текущее число
заполненных временных кадров различаются.

Числовые поля проверяют тип и диапазон. Невалидный текст остаётся в редакторе
поля до исправления и не становится новым параметром. Int64/UInt64 вводятся
точно, без промежуточного округления через `double`.

Валидные изменения параметров и соединений автоматически отправляются
на применение после короткой задержки. Статус сообщает о принятии либо
причине отказа. Пока правка не принята, активным остаётся прежний снимок;
следующая правка не считается принятой вместе с предыдущей.
Команда «Применённый поток данных» возвращает в редактор активную схему.
Индикатор обработки показывает состояние и не служит кнопкой Start/Stop.

## Источники, пресеты и проект

Для AudioSource выбираются loopback или микрофон, затем устройство.
Недоступное сохранённое устройство показывается явно. Сведения о сохранённом
формате схемы отличаются от диагностики фактического захвата; надпись «два
выхода» сама по себе не подтверждает два доступных аппаратных канала.
Обновление списка устройств не должно незаметно выбирать другое устройство.

Генератор позволяет настраивать отдельные осцилляторы; тестовый
источник предназначен для изменяющихся тонов внутри схемы. Наборы параметров
и схема сохраняются в пресетах. Встроенные примеры доступны из меню пресетов.
Первичная тестовая схема не воспроизводит звук через динамики.

Сохранение проекта и изменение активной схемы — разные операции.
Проект хранит черновик, применённый снимок и настройки представления.
Перемещение блоков и настройка панелей не требуют изменения DSP.
Пресет переносит схему и её представление; геометрия главного окна относится
к сеансу. Подробности — [формат проекта](../reference/project-format.md).

## Полотно и окна

Упорядочивание, центровка и масштаб доступны в заголовке потока данных.
Колесо мыши масштабирует относительно указателя, Ctrl+колесо перемещает
полотно вертикально, Alt+колесо — горизонтально. Двухпальцевый свайп
тачпада перемещает полотно по X/Y, pinch меняет масштаб. В Windows используется
Direct Manipulation с резервной обработкой wheel; доступность жестов зависит
от драйвера устройства.

Откройте график через контекстное меню узла. Можно создать внутреннюю область,
вкладку или внешнее окно. Перетаскивание и команды размещения перемещают
существующее представление с его настройками. Escape отменяет перенос.
Одиночный клик по узлу переключает последнюю внутреннюю графическую область;
если такой области нет, он не создаёт новую.

| Действие | Сочетание |
| --- | --- |
| Сохранить / открыть проект | Ctrl+S / Ctrl+O |
| Отменить / повторить правку схемы | Ctrl+Z / Ctrl+Shift+Z |
| Копировать / вставить / вырезать выделение | Ctrl+C / Ctrl+V / Ctrl+X |
| Удалить выделение | Delete или Backspace |
| Упорядочить / центрировать схему | Alt+A / Alt+F |
| Переставить порт на карточке | Alt + перетаскивание порта |
| Открыть график / график во внешнем окне | Alt+G / Alt+Shift+G |
| Следующая / предыдущая вкладка группы | Alt+Right / Alt+Left |
| Отделить активную вкладку | Shift+F4 |
| Скрыть активную панель | Shift+Escape |
| Фокус на потоке данных | F12 |
| Скрыть / восстановить поток данных | Ctrl+Shift+F12 |
| Выбрать открытое представление | Ctrl+Tab |
| Управление процессорами | Alt+P |

Команды схемы действуют в её редакторе. При вводе текста Undo/Redo относятся
к полю; модальные диалоги не пропускают команды полотну.
Список Ctrl+Tab перечисляет открытые представления.

Тема Light/Dark/System и язык RU/EN выбираются общими настройками приложения.
System следует цветовой схеме ОС. Эти настройки сохраняют значения параметров,
связи и камеры. Настройки конкретного графика описаны в [руководстве графиков](graphs.md).
