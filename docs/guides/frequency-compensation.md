# Частотная компенсация по музыкальным измерениям

Основной метод усредняет максимумы отдельных треков по каждой частоте.
Доступны глобальный максимум и верхний процентиль для сравнения. Измерения
сохраняются отдельно от готового профиля; повторное построение не читает музыку.
Полный сценарий и форматы описаны в [Музыкальном спектре](music-spectrum.md#анализ-файлов-и-профили).

Сканер по умолчанию измеряет исходный PCM на Fs каждого трека, FFT4096,
Hann, пиковая амплитуда. Пересчёт через КИХ включается явно. Сетка построения
задаётся в Гц; при объединении недоступные частоты не считаются нулевыми
измерениями. Отсутствие измерений означает единичное усиление.

Полиномиальная аппроксимация Chebyshev и кусочная гладкая PCHIP работают
в координатах линейных Гц с логарифмом амплитуды. Диалог показывает исходный
спектр, аппроксимацию и ошибки обоих методов. Верхний процентиль уменьшает
влияние отдельных громких треков; статистика каждого трека доступна отдельно.

Регуляризация непрерывно уменьшает доверие к амплитудам ниже выбранного
спектрального уровня (по умолчанию −120 дБ). Для отношения r=P/F доверие
равно r²/(1+r²); оно смешивает ограниченную обратную амплитуду с gain=1.
Обратная амплитуда ограничена диапазоном [1, max_gain], по умолчанию ×100.
Нулевая амплитуда и частоты вне измеренного диапазона дают gain=1; края
диапазона сглажены. Порог не удаляет исходные спектральные данные.

Тихие кадры диагностируются отдельно: занятые RMS-группы с шагом 2 дБ
сохраняют число кадров, энергию и средний/максимальный спектры float32.
Порог можно менять после сканирования. Это меняет статистику тихой части,
а не кривую нормализации; тихий сигнал остаётся в основных измерениях.
По RMS нельзя надёжно отличить тихую музыку от аналогового шума.

Старый режим выравнивания среднего спектра сохранён отдельно. Профили v3
без функции требуют точного совпадения frontend. Новая функция пересчитывается
на сетку k*Fs/N текущего объявленного маршрута ArrayFill → ArrayMultiply,
в том числе для Fs 32768, 44100 и 48000 Гц. DSP-тракт не меняется.

Все амплитуды и множители хранятся линейно; децибелы служат отображению и
настройке уровня регуляризации. Нормализация по измеренному корпусу не является
лимитером: новая музыка может иметь более высокие пики. Максимальное усиление
ограничивается профилем, автоматическое обрезание амплитуд не выполняется.
