# Компенсация частотного спектра по трекам

Инструменты → Анализ музыки загружает WAV/FLAC/MP3 и анализирует активные
временные окна по общему спектральному тракту: FFT, окно, спектральная
проекция. Частоты рассматриваются по бинам, а DC (0 Гц) корректируется
отдельно единичным коэффициентом.

## Два независимых метода

**Нормализация по пикам (новый метод).** Для каждой композиции и каждого
FFT-бина сохраняется **максимум амплитуды из активных окон**. Для нескольких
треков берётся наибольший максимум в каждом бине (не среднее максимумов).
Пусть `P[k]` — полученный максимум, `F` — шумовой порог, `Gmax >= 1` —
верхняя граница усиления. Тогда:

`gain[0]=1; gain[k] = clamp(1 / P[k], 1, Gmax)` при `P[k]>F`;
при `P[k]<=F` используется `gain[k]=1`.

Например, при `P[1]=0.5` коэффициент первого положительного бина равен
`2`, при `P[2]=0.1` коэффициент следующего равен `10` (если
`Gmax>=10`). Первая частота **не закреплена** на единичном усилении.
Бины рассчитываются независимо, кривая не обязана монотонно расти:
измеренный пик может быть выше на более высокой частоте.
Когда `P[k]>=1`, исходная амплитуда не подавляется (`gain=1`);
когда `P[k]` ниже шумового порога, недостоверные отсчёты не усиливаются.
При ограниченном `Gmax` целевой максимум может не достичь единицы.

**Выравнивание по среднему (старый метод).** Сохраняется прежняя формула
`gain[k] = clamp(mean(smoothed_spectrum[1:]) /
smoothed_spectrum[k], min_gain, max_gain)` для достоверно измеренных
бинов, с `gain=1` для остальных до ограничения. В этом методе
возможны коэффициенты ниже 1, что является свойством выравнивания
относительно среднего уровня. Радиус сглаживания применяется здесь,
а не к точным максимумам.

## Реализация и воспроизводимость

Отдельная DSP-функция `build_frequency_peak_compensation_curve` создаёт
коэффициенты из уже собранного `peak_spectrum`. Их применение выполняет
существующий `PreparedFrequencyNormalizer`: ещё один FFT-блок не нужен.

Метод (`gain_mode`), общий `peak_spectrum` и максимумы каждого трека
сохраняются в JSON-профиле. Если поле `gain_mode` отсутствует, профиль
интерпретируется в старом режиме `mean_equalization`. Существующие
профили не переписываются автоматически; новый режим требует нового
сканирования.

Все входные пиковые амплитуды и все коэффициенты усиления хранятся
в линейных числах: например, 0,1 × 10 = 1,0. Децибелы используются
только при визуализации измеренного спектра, никогда при умножении данных.
График коэффициентов показывает линейные множители (×), масштабируется
по фактическому максимуму и сообщает, сколько бинов упёрлось в
`max_gain`. Начальный предел для нового анализа — ×100; его можно
изменить в настройках прогона.

Нормализация по измеренным максимумам не равна лимитированию выходного
сигнала. Для новых треков или более высоких динамических пиков возможны
значения больше 1. Автоматическое обрезание амплитуд здесь не выполняется.
Следующий этап — опорные точки, интерполяция и уточнение формы компенсации
по отклику, без изменения текущего измерительного контракта.
