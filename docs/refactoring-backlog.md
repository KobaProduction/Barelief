# Незавершённые задачи перед большим рефакторингом

Текущие наработки зафиксированы по просьбе пользователя как есть. Ниже остаются
известные проблемы, которые ещё не прошли окончательную пользовательскую приёмку.
Попытка создать GitHub issues вернула HTTP 404; задачи сохранены здесь.

## Ресайз и компоновка рабочего пространства

- При сильном сжатии элементы могут наслаиваться и выходить за границы области.
- Перепроверить лишний разделитель при единственной открытой области «Поток
  данных» и пересечение с нижней панелью.
- Правая панель параметров должна иметь изменяемую ширину. Клик по разделителю
  сворачивает её, повторный клик восстанавливает предыдущую ширину. При отсутствии
  выбранного блока показывать подсказку.
- Переключение блоков и графиков не должно самопроизвольно сдвигать рабочую
  область или терять размеры окон.

Часть исправлений уже внесена. Нужно воспроизвести оставшиеся случаи в реальном
окне, привести разделители к единой системе и выполнить короткие адресные проверки.
Длительные прогоны для этой задачи не требуются.

доработана». Конкретный вид токенов и сценарий сбоя в последнем сообщении не
уточнены. Перед изменениями уточнить контекст, зафиксировать воспроизведение и
ожидаемое поведение, завершить доработку и выполнить адресные проверки.
Конкретная причина пока не установлена.
