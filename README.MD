# Qt Visualization

Среда для построения схем обработки сигналов: захват или генерация данных,
численные преобразования, история, графики и сетевой обмен. Схема задаёт маршрут
данных, а интерфейс позволяет редактировать её и наблюдать результаты.

## Состав системы

Переносимое C++20-ядро содержит контракты данных, DSP, исполнение схем и управление
их жизненным циклом. Оно используется настольными приложениями и SDK для
микроконтроллеров.

Графический Qt-runtime `core_app` запускает редактор схем, рабочую область
и графики. Консольный Qt-runtime `pipeline_cli` работает через `QCoreApplication`
без окон. Оба используют общий Qt-слой устройств, конфигурации, таймеров и сети
и общее переносимое вычислительное ядро. Значения «схема», «узел», «график»
и роли компонентов объяснены [перед архитектурными диаграммами](docs/architecture/README.md#термины).

ESP-IDF-компоненты компилируют те же исходники переносимого SDK с платформенными
адаптерами прошивки. Конкретные ресурсы и доступные операции зависят от профиля устройства.
